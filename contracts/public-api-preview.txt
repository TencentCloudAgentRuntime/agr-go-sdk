package agr // import "github.com/TencentCloudAgentRuntime/agr-go-sdk"

Package agr provides the native Go SDK for Tencent Cloud Agent Runtime.
Client is the product-level entry point for Tencent Cloud credentials, regions,
transport policy, and first-class resources. Stable resources cover managed
Sandboxes (lifecycle, files, processes, PTY, watch, code execution, and Cloud
Monitor metrics), Tools, image pre-cache tasks, and Deployments (control plane
and managed HTTP/SSE/WebSocket data-plane connections). Preview prereleases
additionally expose Volume, VolumeTemplate, SessionSpace, Session/Event,
and Registry/Record/Skill-package managers.

Construct a Client with explicit region and credential options for services
that use multiple accounts. The sandbox subpackage exposes environment-backed
shortcuts returning the same Sandbox type. Control and Metrics use the same
Tencent Cloud credential provider.

Remote operations accept context.Context. Use deadlines, preserve structured
errors with errors.As, and never infer that cancellation undid a side effect.
The SDK does not automatically retry mutations. Create waits for readiness but
never assumes deletion ownership of an accepted or replayed instance.

Close a Sandbox to release only its local resources; issue Delete explicitly for
owned remote resources with an independent cleanup context. PTY Close can signal
the remote process, unlike Sandbox or background CommandHandle Close. Close
readers and watches, drain bounded event streams, and do not mutate input maps,
slices or pointed-to options concurrently with an operation.

This pre-release SDK preserves service limitations. Connect can resume or extend
lifetime; Get is read-only. List supports the current service's exact-value AND
filters rather than inventing unsupported projections. Create Env submission
does not establish runtime inheritance or recovery persistence.

const DefaultMaxOutputBytes int64 = 4 << 20

    when no explicit limit is supplied.

type Client struct {
	// Has unexported fields.
}
    Client binds region, providers, endpoints and HTTP configuration. Construct
    with NewClient; do not replace its public service pointer concurrently.

func DefaultClient() (*Client, error)
    DefaultClient lazily caches the first successfully configured
    environment-backed client. Mode, endpoints and provider bindings then remain
    fixed; do not change process environment to switch tenants. Use NewClient
    for explicit multi-account configuration.

func NewClient(opts ...ClientOption) (*Client, error)
    NewClient constructs a client without creating a sandbox. Region defaults
    from TENCENTCLOUD_REGION; request timeout defaults to 30 seconds.
    Explicit control credentials are read for each signed request so temporary
    credentials can rotate within one logical Cloud identity.

func (c *Client) Deployments() *DeploymentManager
    Deployments returns the Deployment control and data-plane service bound to
    this client.

func (c *Client) PreCacheImages() *PreCacheImageManager
    PreCacheImages returns the image pre-cache service bound to this client's
    Cloud identity.

func (c *Client) Sandboxes() *SandboxManager
    Sandboxes returns the sandbox control service bound to this client's Cloud
    identity.

func (c *Client) Tools() *ToolManager
    Tools returns the sandbox-tool control service bound to this client's Cloud
    identity.

type ClientOption func(*clientConfig)
    ClientOption configures NewClient. Use the provided With functions; private
    configuration is not an extension API.

func WithControlPlaneEndpoint(v string) ClientOption
    WithControlPlaneEndpoint selects the official Cloud AGS endpoint (default
    ags.tencentcloudapi.com).

func WithCredential(v CloudCredential) ClientOption
    WithCredential selects Cloud control and Metrics using a static
    SecretID/SecretKey pair.

func WithCredentialProvider(v CredentialProvider) ClientOption
    WithCredentialProvider selects a concurrent, per-request credential source.

func WithDataPlaneDomain(v string) ClientOption
    WithDataPlaneDomain selects the base domain used for Deployment data-plane
    connections. The default is tencentags.com. Pass a hostname only, without a
    scheme, port, or path.

func WithHTTPClient(v *http.Client) ClientOption
    WithHTTPClient supplies trusted HTTP configuration; nil uses SDK defaults.
    The SDK rejects redirects and reuses the transport without taking
    ownership of the shared client. Do not log or forward credentials in custom
    transports.

func WithMonitorEndpoint(v string) ClientOption
    WithMonitorEndpoint selects the official Cloud Monitor endpoint (default
    monitor.tencentcloudapi.com).

func WithRegion(v string) ClientOption
    WithRegion selects the nonempty Tencent Cloud region, overriding
    TENCENTCLOUD_REGION.

func WithRequestTimeout(v time.Duration) ClientOption
    WithRequestTimeout sets a positive per-request timeout (default 30 seconds).
    Use context deadlines to bound orchestration and stream lifetime; this is
    not a sandbox lifetime.

func WithSandboxDomain(v string) ClientOption
    WithSandboxDomain selects the complete Sandbox data-plane hostname suffix,
    such as ap-guangzhou.tencentags.com. It affects public port hosts and
    runtime connections, but not Cloud endpoints or Deployment data-plane
    connections.

func WithTemporaryCredential(v TemporaryCloudCredential) ClientOption
    WithTemporaryCredential explicitly selects Cloud control using a static
    SecretID, SecretKey, and optional session Token.

type CommandHandle struct {
	// Has unexported fields.
}
    CommandHandle observes one process in one data-plane generation.
    Close is local-only; PID must never be reused to control a process after
    reconnection.

func (h *CommandHandle) Close() error
    Close stops local observation, preserving an already completed result.

func (h *CommandHandle) Err() error
    Err reports a locally observed terminal failure, or nil if none has been
    recorded. A nil result while running does not imply successful process exit.

func (h *CommandHandle) Events() <-chan CommandEvent
    Events starts one live observer. Repeated calls return the same channel;
    callers must not use multiple consumers. Wait-only callers need not
    subscribe.

func (h *CommandHandle) PID() uint32
    PID returns the nonzero runtime PID observed before handle delivery,
    not a reconnectable identity.

func (h *CommandHandle) Signal(ctx context.Context, signal ProcessSignal) error
    Signal sends TERM or KILL once to the observed process. Cancellation cannot
    undo a submitted signal, and request success does not establish process
    exit; use Wait.

func (h *CommandHandle) Wait(ctx context.Context) (CommandResult, error)
    Wait limits this wait only. Repeated calls return independent result copies.

func (h *CommandHandle) Write(ctx context.Context, data []byte) error
    Write serializes SendInput requests and waits for each ACK; it never
    retries.

type CommandOptions struct {
	// Args is passed directly to the runtime command; nil means no arguments.
	Args []string
	// Env supplies per-process variables; nil supplies no overrides. Do not mutate the map during

type CommandResult struct {
	// ExitCode is the runtime-reported process exit code.
	ExitCode int
	// Stdout contains retained standard-output bytes; use the producing process's encoding to decode.
	Stdout []byte
	// Stderr contains independently retained standard-error bytes.
	Stderr []byte
	// StdoutTruncated indicates output exceeded its retention limit.
	StdoutTruncated bool
	// StderrTruncated indicates error output exceeded its independent retention limit.
	StderrTruncated bool
}
    CommandResult contains a terminal exit and bounded byte output. A nonzero
    exit code is data, not a transport error.

type Commands struct {
	// Has unexported fields.
}
    Commands executes runtime processes without automatic replay of command side
    effects.

func (c *Commands) Connect(ctx context.Context, pid uint32, opts ConnectCommandOptions) (*CommandHandle, error)
    Connect attaches a generation-bound handle to an existing nonzero PID.
    PID validity and cross-generation availability are decided by the runtime;
    a new Sandbox generation does not make an old handle reusable.

func (c *Commands) List(ctx context.Context, options ...CommandListOptions) ([]ProcessInfo, error)
    List returns the processes visible in the current Sandbox generation.
    At most one options value is accepted; omitting it selects User.

func (c *Commands) Run(ctx context.Context, command string, opts CommandOptions) (CommandResult, error)
    Run executes one required runtime command and returns bounded stdout/stderr
    plus exit code. Nonzero process exit is data, not a transport error.
    There is no automatic command replay; cancellation does not prove remote
    termination.

func (c *Commands) Start(ctx context.Context, command string, opts StartOptions) (*CommandHandle, error)
    Start waits for a nonzero PID. Its context owns the observation lifetime;
    cancellation/Close never sends a remote signal. Use Signal explicitly.

package sandbox // import "github.com/TencentCloudAgentRuntime/agr-go-sdk/sandbox"

Package sandbox provides environment-backed shortcuts for the common
single-identity Sandbox workflow.

Create, Connect, Get, and List delegate to agr.DefaultClient().Sandboxes().
Applications that use multiple Tencent Cloud identities, custom transports,
or explicit endpoints should construct separate agr.Client values instead. Both
entrances return the same agr.Sandbox resource and use the same control-plane,
Metrics, lifecycle, and data-plane implementation.

The default client reads TENCENTCLOUD_REGION, TENCENTCLOUD_SECRET_ID,
TENCENTCLOUD_SECRET_KEY, and optional TENCENTCLOUD_TOKEN. Its configuration
and provider binding are cached after the first successful initialization;
environment variables must not be used to switch accounts in a running process.
